# Text Extractor

macOS and Windows. On Mac, Text Extractor requires macOS 14 or later. Open **Settings → Advanced** and enable **Text Extractor**. **Win + Shift + T** opens the editor flow: after release, the selected crop flies from its original rectangle into the screen's center, then settles above the editor as the text appears. Basic OCR runs during the flight. **Ctrl + Win + Shift + T** selects an area over the live desktop, reads it locally, copies the text, and closes without showing a screenshot, editor, or buttons. Both shortcuts can be changed independently in Settings. Duplicate assignments and combinations already registered by another application are rejected while keeping the previous shortcuts. Legacy preferences acquire the Quick Copy default automatically; the former Ctrl + Shift + E and Ctrl + Win + Shift + T editor defaults migrate once, while explicit custom assignments are preserved on subsequent launches.

On Windows, when assigned to either action, the two default combinations are intercepted by a hidden Pulse helper process while enabled, consuming the T press, repeat, and release before Windows' Snipping Tool sees the chord. Other keys and modifier releases pass through. Modifier state is tracked directly, with no typed text recorded. A bounded non-blocking queue sends actions off the hook thread. The helper has no WebView2 windows, so focusing Settings cannot bypass its hook. Private inherited pipes carry shortcut configuration and actions; closing Pulse closes the input pipe and terminates the helper. The same executable starts the helper before initializing Tauri, so there is no second tray icon or additional download. Disabling the feature restores Windows' normal shortcut handling. Other custom combinations use Windows global shortcut registration. Shortcut recording reports either intercepted chord or an existing registered custom shortcut to the active recorder without starting a capture.

Basic is the initial default for both shortcuts. If the selected advanced provider is unavailable, both shortcuts use Basic, and the editor shows only the screenshot, editable text, and **Copy**. When the provider is available, the editor adds **Basic / Advanced** above the screenshot and **Translate** to the left of **Copy**; Settings exposes a default mode slider for each shortcut. Advanced Quick Copy sends only the selected crop to the selected provider and copies its result without an editor. The default modes persist independently. An Advanced editor default starts centered with the zoomed screenshot and shimmer, then reveals its result after the current shimmer pass finishes.

Switching to Advanced fades away the editor, centers the screenshot and slightly enlarges it, then runs a broad full-height shimmer from left to right. When the model's result arrives, the current 2.4-second pass finishes at the right edge before the screenshot shrinks and moves upward and the editor and buttons fade in below it. Switching modes retains each mode's edited draft, cancels the previous request, and reuses completed results without another paid call. Reduced motion skips the flight, zoom, and shimmer wait. Errors leave the mode selector usable and preserve existing edits.

Edit the returned text and choose **Copy** to copy and close. **Translate** opens a language picker and replaces the current mode's editor content with a translation of its current text. Press **Escape** or click outside the result to dismiss; invoke the shortcut again to take a fresh capture. A drag that starts inside the editor does not dismiss the overlay when released outside.

Screenshot and editor use squircle corners where the system webview supports them, with rounded corners as a fallback. The translation symbol comes from `src/translation-icons/translate-icon.svg` on the Live Translate branch, with the background circle removed. Both centered pills use the same foreground and background colors, with Translate on the left and Copy on the right. Accessible status announcements are offscreen; there are no visible hints, headings, or close/reselect/done controls.

The monochrome overlay follows Pulse's Appearance selection, including the resolved Auto schedule on Windows. On Mac it follows the system appearance. The native window is created with Pulse's current visual theme and updates through the same controller as the tray, including transition rollbacks. The webview exposes that theme through `prefers-color-scheme`. The blurred backdrop is grayscale; the selected screenshot retains its original colors.

Settings now has **General**, **Advanced**, and **Appearance** pages with a sliding tab indicator and keyboard navigation. General contains startup behavior; Appearance contains Auto scheduling and tray/menu-bar icon style. The Advanced page contains Text Extractor and advanced-provider setup on both platforms. Mac adds a Screen Recording permission action and Apple Intelligence / OpenAI API selection. Page changes preserve saved state and close open dropdowns. The selected settings pill is black in light mode and white in dark mode. Identical, counter-moving labels are clipped inside the sliding pill so the selected color follows its edge without changing the font; reduced motion and forced colors have accessible fallbacks.

Settings is a wider floating squircle panel with an internal title, a draggable header, and a centered **Done** button. Done and Escape dismiss it; there is no native title bar or close button. Shortcuts expand and collapse smoothly with the Text Extractor toggle. When the selected advanced provider is available, the compact mode sliders sit immediately to the left of their shortcut buttons. The panel follows Pulse’s current appearance and keeps the same size across pages, with scrolling on short screens or when errors need extra space.

## macOS integration and Apple Intelligence

Mac defaults are **Option + Shift + T** for the editor and **Control + Option + Shift + T** for Quick Copy. All combinations use the system global-shortcut registrar; Windows-specific keyboard interception remains isolated under `src-tauri/src/text_extractor/windows/`.

`session.rs` owns the shared windows, cancellation, crop binding, clipboard, notices, and animation IPC. Native adapters provide capture, positioning, shortcuts, and Basic OCR. Mac uses a small Objective-C bridge to AppKit, ScreenCaptureKit, and Vision. It tracks each display's ID, global point coordinates, and backing-pixel dimensions separately, positions overlays on that display across Spaces/fullscreen apps, excludes the selector and notice from capture, and exports SDR sRGB pixels. Permission is requested only through the Settings button; startup and prewarming never request screen access or capture pixels. Revoking permission or disconnecting/changing a display fails the capture rather than using stale geometry.

Basic uses `VNRecognizeTextRequest` revision 3 in accurate mode with automatic language detection, prioritizing system languages plus English, Ukrainian, and Russian when supported. Language correction is disabled to preserve identifiers and literal text. The output keeps word spacing, groups fragments by row, and retains paragraph gaps. It requires neither Apple Intelligence hardware nor an API key, ONNX Runtime, or a model download. OCR runs off the event thread; cancelling discards any late result.

Mac selects **Apple Intelligence** by default and checks availability without sending a prompt. **OpenAI API** is an explicit alternative. The selection survives restart, and switching providers cancels the current capture so no pending image is silently redirected. There is no automatic fallback between cloud providers. Basic remains available independently.

The Apple option uses the macOS 27 **Private Cloud Compute** model for image extraction and translation, with light reasoning. It requires an Apple Intelligence-capable device/region, macOS 27, and Apple's managed `com.apple.developer.private-cloud-compute` entitlement. Pulse checks the signed entitlement, native model availability, and daily quota; missing access, system readiness, quota, or build support is shown beside the selector with **Retry**. macOS 26's on-device text-only model is not used as a substitute for image extraction. Framework errors are mapped to plain messages without exposing prompts. Dismissal and the two-minute timeout cancel the Swift task and discard late callbacks.

Build the cloud integration with Xcode 27 selected, for example:

```sh
DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer pnpm tauri build
```

The build script compiles and links `AppleIntelligence.swift` only when the selected SDK is 27 or newer. Older SDKs still build the cross-platform app, with an explicit unavailable message for Apple Intelligence. Both Foundation Models and ScreenCaptureKit are weak-linked so missing newer frameworks do not prevent launch. The app's minimum macOS version is 12 for the Swift concurrency runtime; text capture itself is gated to 14, and Apple cloud calls to 27.

For distribution, obtain Apple's PCC approval and use a signing identity/provisioning profile granting that entitlement. The ordinary ad-hoc development build does **not** pretend to have approval and displays access denied. No entitlement is self-granted or added to standard releases. [Apple's access requirements](https://developer.apple.com/wwdc26/guides/apple-intelligence/) and [PCC API documentation](https://developer.apple.com/documentation/foundationmodels/adding-server-side-intelligence-with-private-cloud-compute) describe eligibility and daily usage limits.

This reconfiguration was compiled without running capture, OCR, model requests, clipboard actions, UI previews, or the acceptance pipeline. Manual Mac checks remain: permission grant/revocation, both shortcuts, recording/custom bindings, Retina/mixed-DPI displays, negative origins, Spaces/fullscreen, tiny/mixed-language crops, animation timing, appearance, notices, provider switching/retry, cancellation, and signed PCC access. The historical Windows results below do not validate this new Mac integration.

## Credential compatibility

`src-tauri/src/openai_credentials.rs` uses the exact Live Translate credential identity from the `live-translate` branch: service `app.pulse.desktop`, account `openai-api-key`, with `keyring`'s native store. Keys are shared, never kept in the JSON preferences or returned to JavaScript. Updating the key updates it for both features. The explicit Remove action removes the shared key for both features. Live Translate itself is not merged into this branch; when combining the branches, its existing helpers can delegate to this module without migrating credentials. Text Extractor uses a separate `text-extractor.json` preferences file and independent commands.

## Capture and request lifecycle

Pulse prepares a hidden transparent webview when the feature is enabled and after a capture closes. The shortcut path only reads monitor geometry, positions that preloaded window, and shows the live selector; it does not capture/encode a screenshot, transfer pixels, or read credentials. Native window entrance transitions are disabled. The selection surface intercepts the mouse over the live desktop, including monitors left of or above the primary display.

Pixels are captured only on release. Windows Quick Copy captures only the crop; Mac captures the selected display and crops its backing pixels. Quick Copy hides the selector, and runs its configured recognizer without returning images or text to the webview. Empty recognition leaves the clipboard intact and shows the small “No text found” notice; failures preserve the clipboard and report the error in Settings. A new shortcut cancels pending Quick Copy work so a slow Advanced request cannot block a fresh selection or overwrite its clipboard result. The editor captures the selected monitor once and retains a top-down BGRA buffer. Only the bound crop is converted and PNG-encoded before its flight starts. A separate cancellable command prepares a small backdrop while the crop is already moving; neither backdrop encoding nor decoding gates the animation. Only after selection is the frozen background blurred. Other monitors are untouched. The selector is excluded from capture with `WDA_EXCLUDEFROMCAPTURE` (Windows 10 version 2004+).

Closing the last selector does not quit Pulse; explicit Quit and updater restart still work. The replacement selector is prepared in the background. The keyboard hook only updates shortcut state and sends a non-blocking action; Windows-menu input masking runs on the action thread. Remapped/injected shortcut keys are supported, and only the tagged unused mask key is ignored. When a capture closes, the next hook event resynchronizes modifier/T state with Windows, recovering releases consumed while the selector was focused and preserving repeat suppression if the original chord is still held.

Every active and preloaded window has a unique label. Ready/start handshakes avoid cold-webview startup work, and matching-label cleanup prevents a delayed watchdog or cancelled Quick Copy from closing a newer session. Display changes invalidate the selected monitor geometry before capture. On Windows, Basic uses PP-OCRv5 Mobile detection and Cyrillic recognition through CPU ONNX Runtime. It handles Latin and Cyrillic text in one pass, including English, Ukrainian, and Russian, without Windows language packs. The runtime is statically linked into Windows builds; there is no Python, GPU driver, or separate runtime installation. Models download once when Text Extractor is enabled and preload in the background. Valid cached models load without a network request. Settings shows setup progress and Retry if setup fails; Basic reports that setup is needed until the sessions are ready and never falls back to a paid request. OpenAI remains on Luna; Apple Intelligence is a separate Mac provider.

Model URLs and SHA-256 digests are pinned to the RapidOCR v3.9.2 registry in `src-tauri/src/text_extractor/windows/ocr_models.rs`. Requests identify Pulse with a User-Agent because ModelScope’s CDN rejects an absent header with HTTP 403. If ModelScope fails, each file falls back to the DjB314/RapidOCR Hugging Face mirror pinned to commit `04e88d0483f0bfcdd0f29429594244c10bfc2867`; both sources must match the same upstream SHA-256 digest. HTTP/network failures are logged without signed CDN URLs, and Settings identifies failed sources if both hosts fail. Disk errors stop immediately instead of retrying another host. Both downloads require HTTPS, have bounded size/timeouts, and are verified before partial files are renamed into the versioned cache in `%LOCALAPPDATA%/app.pulse.desktop/ocr/ppocr-v5-cyrillic-rapidocr-3.9.2`. Existing files are verified at startup; corrupt/incomplete downloads can be retried. Disabling cancels setup; re-enabling uses existing verified downloads. Prepared CPU sessions are retained until exit, with idle thread spinning disabled. Licenses and upstream attribution are bundled in `src/ocr-notices.txt`.

The recognizer reads dictionary line terminators without creating an extra empty character and verifies the dictionary length against the model output. This keeps the final space class at its correct index, instead of dropping all spaces within a detected line. The downloaded weights remain unchanged. Small selections keep background-matched padding and bounded enlargement. Detection is limited to a 1536-pixel long edge, recognized fragments are grouped into rows and read left-to-right, and empty/low-confidence output leaves the clipboard untouched. This initial integration targets upright screen text; quality, speed, and very small/mixed-language crops still need the user’s Windows acceptance run. No model inference, benchmarks, or tests were run for this replacement, at the user’s request.

Only when Advanced uses OpenAI is that crop sent to `https://api.openai.com/v1/responses`, using `gpt-5.6-luna`, `reasoning.effort: none`, and `store: false`. The prompt requests only the intended main text, in its original language. Screenshot instructions are treated as source text. Images stay in memory and are discarded when the capture closes; no screenshot files are written.

Translation sends only the current edited text to the selected provider. OpenAI uses Luna with no reasoning and the shared key; Apple uses its cloud model. Both support request cancellation. The picker supports English, Ukrainian, German, Spanish, French, Italian, Polish, Portuguese, Japanese, Korean, Simplified Chinese, and Arabic. The backend validates the selected language against this list and caps input at 100,000 UTF-8 bytes. While a translation is pending, the text remains visible and temporarily read-only. Failed or empty translations leave it intact and allow retrying, editing, or copying.

The request has a two-minute timeout, a bounded response size, and cancellation when its window is closed or the feature is disabled. Ordered request IDs prevent late requests, cancellation messages, or responses from overriding a newer mode or capture. Local OCR runs on a blocking worker with reusable CPU sessions; cancellation discards its result and skips remaining lines, though a model call already in progress may finish. Clipboard errors preserve the edited text and keep the window open. Native screenshots of protected content may be blank. HDR colors and exclusive fullscreen applications need verification on a Windows desktop.

API contract sources: [Luna model](https://developers.openai.com/api/docs/models/gpt-5.6-luna), [image input](https://developers.openai.com/api/docs/guides/images-vision).

The shared API key uses Live Translate’s Save/Remove flow, including validation before storage. Save displays “Checking key…” while a small Luna Responses request (16 output tokens maximum, no reasoning, `store: false`, no screen content) checks authentication and model access. Only a completed response allows replacing the stored key; invalid keys, service errors, and timeouts preserve it. Saved keys are represented by a fixed mask; the stored secret is never sent back to the webview. Typing replaces the mask with the new password input. Removing the shared key disables OpenAI availability while keeping Basic OCR and a configured Apple provider usable.

## UI preview without API calls

Run `node scripts/text-extractor/preview.mjs` and open `http://127.0.0.1:4178`. This injects an isolated fixture bridge into the actual frontend. It has no real API, key storage, clipboard, or capture access, and is outside the packaged `src` directory.

- `/settings.html?enabled&key` — preview both shortcut mode sliders; omit `key` or `enabled` to check the simpler states.
- `/?key&editorMode=advanced` — start directly with Advanced extraction.
- `/` — select an area and preview its flight into the editor. A fixture desktop canvas continues animating during selection.
- `/?quick` — select and copy with no result UI or API-key access.
- `/?warm` — stay preloaded until a `pulse-capture-start` DOM event starts the fixture session.
- `/?scenario=capture-pending` or `capture-error` — exercise delayed capture cancellation and errors.
- `/?scenario=backdrop-pending` or `backdrop-error` — verify that backdrop preparation cannot hold up the crop flight or usable editor.
- `/?key&scenario=demo` — preview the Basic crop flight, then switch to Advanced for a simulated 6.5-second request to preview the full animation. Emulate light/dark color schemes in a desktop browser to preview Pulse's two palettes.
- `/?key&scenario=error`, `empty`, or `pending` — exercise Advanced result states. `/?scenario=basic-error`, `basic-empty`, or `basic-pending` exercise local recognition states; `clipboard-error` simulates a copy failure.
- `/?key&scenario=translation-error`, `translation-empty`, or `translation-pending` — exercise translation failures and cancellation. Successful fixtures provide German and Ukrainian sample translations; other languages echo the input.
- `/settings.html` — Windows settings with no key; `?key` simulates a shared saved key.
- `/settings.html?scenario=key-error` or `shortcut-error` — simulate saving failures. `key-pending`, `key-invalid`, and `key-offline` cover delayed validation, rejected credentials, and connection failure.
- `/settings.html?platform=macos&enabled` — Mac settings with Apple selected and available; add `&scenario=apple-denied` for the error/Retry state, `&scenario=capture-denied` for screen permission, or `&provider=openai&key` for saved OpenAI credentials. These are fixtures only.

`node --test tests/extraction-geometry.test.mjs` checks drag directions, monitor bounds, and fractional DPI. Rust unit tests verify crop bounds, both shortcut chords, repeats, modifier releases, disabled/recording behavior, stale session cleanup, and request/response data structures with local fixtures. These never contact OpenAI or access a saved key. The desktop verification workflow compiles and tests on Windows and macOS without API credentials.
